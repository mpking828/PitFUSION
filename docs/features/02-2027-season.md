# Feature 2 — 2027 season support

Status: **designing** (prep now, finish after kickoff). Size: S–M.

## Context

The 2027 game is announced **2027-01-09**. Most of the work is a config addition plus a
codebase audit; the game-specific part is blocked until the field/scoring is known.

## What's already year-safe

Audit result (as of V3.0.0): the running year is **always** `new Date().getFullYear()` —
every Statbotics call (`team_year`, `team_matches`), the setup-screen event fetch, and the
Nexus-key-from-FIRST-code derivation compute it dynamically. There is **no hardcoded 2026
in logic** — only:

- `public/index.html`: the event-code input `placeholder="e.g. 2026mabos"` and one
  code comment (`// e.g. TBA "2026bc2"...`). Cosmetic.
- `public/config.js`: `EPA_FIELDS` has `2026` and `2025` entries. `renderEpa` already
  falls back to the newest year present if the current year is missing, so 2027 works
  degraded until an entry is added.

## Do now (not blocked)

1. Bump the placeholder to a neutral form (`e.g. 2027mabos` shortly before kickoff, or
   drop the year: `e.g. <year>mabos`).
2. Add a top-of-`config.js` comment: "Add an `EPA_FIELDS[<year>]` entry each January
   once Statbotics publishes the new breakdown field names."
3. Confirm TBA `score_breakdown.[red|blue].rp` still holds for 2027 once matches exist
   (the code comment claims "works 2016+, field name consistent" — re-verify in week 1).

## Do after 2027-01-09 kickoff

1. Add `EPA_FIELDS[2027]` to `config.js` — since 7b, the `key`s are the year-agnostic
   Statbotics per-match fields (`epa`, `auto_epa`, `teleop_epa`, `endgame_epa`,
   `rp_1_epa`, `rp_2_epa`), so **just copy the 2026 block and rename the RP labels**
   for the new game. No API lookup needed.
2. Confirm 2027 still has ≤ 3 RPs (`rp_1_epa` … `rp_3_epa`); add an `rp_3_epa` row if
   the game has a third. TBA `score_breakdown.[red|blue].rp` (used for the match-list RP
   column) — re-verify the field name in week 1.
3. Sanity-check the playoff/finals labelling (`comp_level` `sf`/`f`, `set_number` as the
   playoff match number) against the first 2027 events — this has broken on format
   changes before.
4. Bump `VERSION` + `version.json`, tag, release.

## Verification

Before kickoff: load with the current year, confirm nothing regressed. After: point at a
week-1 2027 event, walk every screen, confirm EPA charts render with the new fields and
RP shows correctly.
